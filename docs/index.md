**TutorContacts is a desktop application for independent private tutors to manage student records.** It keeps student and guardian contact details together with tutoring information such as subjects and education levels.

TutorContacts is optimized for users who prefer typing. Its command-line interface allows frequent contact-management tasks to be completed quickly while retaining the convenience of a graphical interface.

* To start using TutorContacts, see the [_Quick Start_ section of the **User Guide**](UserGuide.html#quick-start).
* To learn how TutorContacts is designed and developed, see the [**Developer Guide**](DeveloperGuide.html).
* To view the source code or report a problem, visit the [**TutorContacts GitHub repository**](https://github.com/AY2627S1-CS2103T-W10-3/tp).
